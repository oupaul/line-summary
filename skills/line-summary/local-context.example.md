# Local Context Template

複製這份檔案成同資料夾下的 `local-context.md`（已被 `.gitignore` 排除，
不會被 commit），填入你自己公司的實際資訊。這份 example 檔案本身要保持
通用，不要放真實公司/客戶/同事資料。

## 公司名稱 / LINE 群組命名前綴

<例如：公司群組都叫「XX資訊-客戶名」，這裡就填「XX資訊」>

## 內部人員姓名模式

用來判斷「這是自己人回覆」還是「客戶方回覆」：

- <內部人員常見前綴，例如「公司簡稱-某某某」>
- 帳號本人：<你自己在 LINE 上顯示的名字>（自己發的訊息用 `_profile` 解析，
  不會有前綴）
- 內部稽核群組（如果有）：<群組名稱> — <負責貼報告的人> 每天貼自動化語意
  稽核報告，可跟自己抓的清單交叉驗證
